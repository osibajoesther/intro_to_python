This problem is designed to assess students’ ability to organize a Python program with functions, validate inputs, and use arithmetic to solve a practical problem. Students use the number of people registered, the room’s capacity, and the registration fee to determine whether the event fits in the room and to calculate expected revenue by multiplying registrations by the fee. The program then returns two strings: one reporting the expected revenue and one describing the room’s capacity status.
The most challenging part may be understanding how the functions work together. A validation function should return True or False. Then determine if the calculation should proceed. Students also need to distinguish between returning a result and printing it, and to use Boolean logic to keep invalid inputs from reaching the calculations.

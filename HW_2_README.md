This problem is designed to assess students' ability to use functions to organize a larger Python program. This seems to be a skill that the class, including me, seems to struggle with. The validation function requires students to use Boolean logic with multiple conditions and return either True or False. The driver code then has to use that returned value to determine whether the rest of the program should run. The most challenging part for an average student will likely be understanding that validate_event() should not print the result itself. Instead, it should return information to the driver code, which then decides what to do with that information. Students must also correctly use Booleans to prevent invalid inputs from reaching the calculation functions. In completing this problem, we should be able to understand to a greater extent how individual functions interact with one another and how validation can control the flow of an entire program.
